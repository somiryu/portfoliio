# Developer Portfolio | Somiryu

Modern, gamified developer portfolio built for a **Senior Full Stack Developer & Tabletop Industry Specialist**. This project is specifically architected to demonstrate high-complexity problem solving, full-stack mastery, and industry-specific expertise.

## 🚀 Vision
The portfolio uses an **Industrial-Tech Aesthetic** combined with subtle gamification to highlight over 15 years of immersion in the tabletop industry. It focuses on the bridge between creative game design and robust software engineering.

## 🛠 Tech Stack
- **Framework:** [SvelteKit](https://kit.svelte.dev/) (Svelte 5)
- **Backend Mastery:** Ruby on Rails, Go, Python (Django)
- **Styling:** Vanilla CSS (Custom Design System)
- **Icons:** [Lucide-svelte](https://lucide.dev/)
- **Workflow:** The Antigravity Method (AI-Assisted Architecture)

## 🏗 Key Features
- **Industry Journey:** A detailed timeline of professional experience in the board game ecosystem.
- **Mastery Visualization:** Gamified skill bars reflecting technical proficiency levels.
- **Featured Ecosystems:** Deep-dives into complex projects like BG-Forge and Gengine.
- **AI Workflow Section:** Documentation of the modern "Vibe Coding" and architecture strategy.

## 💻 Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Production build:**
   ```bash
   npm run build
   ```

## 📄 Content Management
All portfolio content (profile, skills, projects, experience) is centralized in:
`src/lib/portfolioData.js`

Edit this file to update the information displayed across the site.
